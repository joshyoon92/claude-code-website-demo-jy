1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “같은 화면에서 이어받기”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. Two named cursors edit a shared card in sequence: one finishes the headline, hands the card to a second editor, and a review badge resolves the handoff. 시작은 빈 공동 편집 카드. 0.35초에는 첫 편집자가 제목 위치로 이동한다. 1.05초에는 제목을 입력한다. 2.8초에는 두 번째 편집자가 검토를 이어받는다. 4.05초에는 완료 배지가 나타난다. 마지막에는 EDITED → REVIEWED 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘.
