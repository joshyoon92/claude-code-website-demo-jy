1080×830 크기의 6.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “한 문장이 네 장의 시안으로”. 입력창에 프롬프트가 타이핑되고 입력창이 위로 접히며 네 개의 일러스트 시안이 점진적으로 완성된다. 오른쪽 위 시안을 클릭하면 캔버스 전체로 펼쳐진다. 기존 laptop-type-zoom의 장치 화면과 달리 화면 내부에서 입력→4개 결과→선택 확대를 하나의 시선 경로로 연결한다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 프롬프트 입력; 1.5초: 입력창을 위로 정리하고 네 시안 공개; 3.35초: 오른쪽 위 시안을 커서로 선택; 4.25초: 선택한 이미지가 캔버스 전체로 확대; 5.45초: 완성된 시안 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
