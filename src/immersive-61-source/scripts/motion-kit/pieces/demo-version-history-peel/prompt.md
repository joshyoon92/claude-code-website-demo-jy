1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “이전 버전을 꺼내 복원”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. Three stacked versions peel apart along depth and time, a cursor selects the middle revision, and that revision returns to the front as the restored design. 시작은 겹쳐진 세 가지 버전. 0.6초에는 쌓인 버전 카드가 양옆으로 펼쳐진다. 2.4초에는 가운데 버전을 선택한다. 2.6초에는 선택한 버전이 다시 전면으로 나온다. 3.5초에는 복원 완료를 표시한다. 마지막에는 VERSION 2 RESTORED 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
