1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “폭이 바뀌면 구조도 바뀐다”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A responsive canvas is physically resized by its edge handle; three columns reflow into a compact vertical stack while preserving content order. 시작은 세 열로 배치된 콘텐츠. 1.3초에는 캔버스의 오른쪽 조절점을 안으로 당긴다. 1.7초에는 세 열의 카드가 순서대로 세로 배치로 바뀐다. 2.8초에는 좁은 화면 폭과 동일한 내용을 확인한다. 마지막에는 3 COLUMNS → 1 STACK 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
