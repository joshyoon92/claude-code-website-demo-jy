1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “입력이 곧 대시보드가 된다”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. Three filled form rows preserve their values while reorganizing into dashboard tiles and a generated launch checklist. 시작은 프로젝트 입력 폼. 0.5초에는 프로젝트 이름을 입력한다. 2.5초에는 생성 버튼을 누른다. 3.05초에는 입력한 목표와 일정이 대시보드로 배치된다. 마지막에는 INPUTS → WORKSPACE 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
