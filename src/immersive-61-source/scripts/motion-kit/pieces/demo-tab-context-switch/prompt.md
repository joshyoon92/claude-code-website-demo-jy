1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “탭을 바꿔도 맥락은 그대로”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A persistent project identity travels across three tabs as their content switches from brief to draft to review, keeping the selected object anchored. 시작은 기획 탭의 프로젝트 요약. 1.35초에는 기획에서 제작 탭으로 이동한다. 1.5초에는 프로젝트 제목을 유지하며 본문만 교체한다. 3.5초에는 검토 탭에서 완료 상태를 확인한다. 마지막에는 BRIEF → BUILD → REVIEW 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘.
