1080×830 크기의 6.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “이미지가 글자의 표면이 될 때”. 가득 찬 이미지 위로 커다란 네 글자의 윤곽이 나타난다. 이미지 주변이 차콜로 잠기면서 그림이 글자 안에만 남고 전체가 한 장의 타이포그래피 포스터로 정리된다. 기존 text-window-mask는 마스크 텍스트의 단독 효과다. 여기서는 먼저 보여준 이미지가 같은 좌표에서 글자의 재료가 되는 편집 과정을 한 샷에 보존한다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 입력 상태를 읽을 수 있게 제시; 1.0초: 조작과 변환 시작; 3.2초: 시각적 결과 연결; 5.4초: 결과를 정리하고 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
