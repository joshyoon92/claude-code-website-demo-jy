1080×830 크기의 16.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “입력에서 이미지, 움직임, 타이포까지”. 프롬프트를 입력하고 펼쳐지는 이미지 안으로 진입한다. 동일 이미지가 시간축 위에서 움직인 후 크기를 줄이며 큰 글자의 O 안으로 들어가 하나의 포스터가 된다. 모든 변환에 같은 아치 조형물을 유지한다. 기존 film-seamless-oneshot의 장치 이동과 달리 하나의 화면 내부에서 입력·시안·영상 재생·타이포 포스터까지 변환되는 16.8초 원테이크다. 서로 다른 장면을 이어 붙인 덱이 아니다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 프롬프트 입력; 2.65초: 입력란이 접히면서 이미지 등장; 4.35초: 이미지 안으로 카메라 진입; 6.6초: 필름스트립이 열리고 같은 이미지가 움직임; 10.8초: 이미지가 O 자리로 축소되며 FORM 포스터 완성; 13.7초: 완성된 타이포 포스터를 3초 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
