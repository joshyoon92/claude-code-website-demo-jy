1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “댓글에서 수정 완료까지”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A comment pinned to a headline opens, the requested wording is changed in place, then the comment collapses into a resolved marker without replacing the design. 시작은 댓글이 달린 히어로 문구. 1.2초에는 문구에 달린 댓글을 연다. 2.6초에는 피드백에 맞춰 문구가 바뀐다. 4.1초에는 댓글을 해결하고 체크 표시로 접는다. 마지막에는 FEEDBACK → EDIT → RESOLVED 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
