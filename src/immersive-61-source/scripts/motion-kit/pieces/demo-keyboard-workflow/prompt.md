1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “손이 기억하는 빠른 편집”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A keyboard command duplicates a card, an arrow key moves the duplicate into alignment, then Enter commits the changed layout with a visible result. 시작은 한 개의 선택된 카드. 0.55초에는 복제 단축키가 눌린다. 0.75초에는 동일한 카드가 생성된다. 1.85초에는 방향키로 다음 열에 정렬한다. 3.5초에는 엔터로 배치를 확정한다. 마지막에는 DUPLICATE → ALIGN → COMMIT 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
