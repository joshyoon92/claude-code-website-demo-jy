1080×830 크기의 6.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “텍스트 토큰이 그림의 재료로”. 형태·빛·재질을 뜻하는 네 개의 텍스트 토큰이 쪼개져 미세한 타일로 이동한다. 타일이 풍경의 명암 구획을 채운 후 벡터 아트로 선명해진다. 기존 mosaic-assemble의 단순 사진 조립과 달리 입력 토큰→이미지 공간의 배치→선명한 결과라는 설명용 의미 변환을 만든다. 실제 모델 내부 작동은 묘사하지 않는다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 입력 상태를 읽을 수 있게 제시; 1.0초: 조작과 변환 시작; 3.2초: 시각적 결과 연결; 5.4초: 결과를 정리하고 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
