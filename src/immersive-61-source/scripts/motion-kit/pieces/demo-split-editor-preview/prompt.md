1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “코드를 쓰면 화면이 따라온다”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A split editor highlights and types a button label, then the exact same label updates in the adjacent live preview before the preview expands. 시작은 코드 편집기와 미리보기. 1.1초에는 코드 안의 버튼 문구를 입력한다. 2.65초에는 옆 미리보기에 같은 문구가 반영된다. 3.55초에는 완성 화면이 중앙으로 확대된다. 마지막에는 CODE → LIVE PREVIEW 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
