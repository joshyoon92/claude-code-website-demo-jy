1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “명령 한 줄로 장면을 열다”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A command palette types a search, selects one matching action, then expands that exact result into a working canvas. 시작은 프로젝트 목록. 0.35초에는 명령 팔레트가 열린다. 0.95초에는 새 캔버스를 입력한다. 2.2초에는 검색 결과 하나를 선택한다. 3.5초에는 선택한 카드가 전체 캔버스로 확장된다. 마지막에는 CANVAS READY 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘.
