1080×830 크기의 6.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “곡선을 타고 들어와 문장이 되다”. 같은 문장이 S자 곡선을 따라 화면 안으로 들어온다. 곡선의 진폭이 줄어들면서 텍스트가 수평 기준선 위로 정렬되고 마지막 단어까지 선명하게 읽힌다. 기존 marquee-band-collage의 반복 띠와 달리 하나의 문장을 곡선 경로에서 평면 제목으로 변환한다. 같은 글자가 유지되고 궤적이 정리된다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 입력 상태를 읽을 수 있게 제시; 1.0초: 조작과 변환 시작; 3.2초: 시각적 결과 연결; 5.4초: 결과를 정리하고 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
