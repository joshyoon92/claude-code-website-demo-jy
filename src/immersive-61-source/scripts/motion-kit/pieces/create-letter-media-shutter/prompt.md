1080×830 크기의 6.8초 모션그래픽을 HTML·CSS·GSAP로 만들어줘. 주제는 “글자가 열리면 장면이 시작된다”. 네 글자가 각각 세로 셔터처럼 화면을 채운다. 같은 축을 중심으로 글자 패널이 옆으로 열리면서 뒤의 한 장면을 드러내고, 마지막 패널이 닫히지 않고 화면 밖으로 정리된다. 기존 letter-clip-shapes처럼 글자 안에 도형을 넣는 효과가 아니라 글자 자체를 화면 가림막의 물리적 면으로 사용한다. 배경은 차콜 #0A0A0A, 밝은 면은 페이퍼 #F4F3EE, 한 프레임의 주목 지점 하나만 라임 #D4F527로 강조해. 글자는 Pretendard 또는 Geist 400~600 굵기로 읽기 크게, 장식보다 실제 입력과 변환 결과가 보이게 해. 타이밍은 0초: 입력 상태를 읽을 수 있게 제시; 1.0초: 조작과 변환 시작; 3.2초: 시각적 결과 연결; 5.4초: 결과를 정리하고 유지. 하나의 paused GSAP 타임라인으로 임의 시점으로 이동해도 같은 결과가 나오게 해. 시계·무작위·네트워크 호출 없이 로컬 폰트와 원본 SVG 일러스트를 사용해. 문구와 이미지는 변수로 바꿀 수 있게 하고 “설명용 재연”을 표시해. 실제 AI 결과나 성능을 입증하는 것으로 표현하지 마.
