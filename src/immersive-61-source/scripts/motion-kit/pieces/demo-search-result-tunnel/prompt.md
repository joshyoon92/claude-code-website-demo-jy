1080×830 크기의 6.5초 모션그래픽을 만들어줘. 제목은 “검색에서 답으로 들어가기”. 노트북이나 휴대폰 외곽 없이 화면 안에서 바로 작동하는 인터페이스로 보여줘. A query filters a stack of document results, then the selected answer card scales through the screen to become an open document with its cited answer. 시작은 세 개의 문서 검색 결과. 0.4초에는 검색어를 입력한다. 1.65초에는 관련 없는 결과가 약해진다. 2.6초에는 선택한 문서가 화면을 채운다. 3.25초에는 답과 출처가 나타난다. 마지막에는 QUERY → SOURCE → ANSWER 상태를 0.8초 이상 읽게 해줘. 차콜 배경, 흰색과 회색 UI, 핵심 결과 한 곳에만 라임색 #D4F527을 써줘. Geist와 Pretendard 400~600 굵기, 작은 화면에서도 읽히는 큰 글자, 부드러운 커서와 인과관계가 분명한 동작을 사용해줘. HTML/CSS와 일시 정지된 GSAP 타임라인 하나로 만들고 임의 시점 탐색이 가능하게 해줘. 제품 로고나 실제 앱의 성과 수치를 꾸며내지 말아줘.
